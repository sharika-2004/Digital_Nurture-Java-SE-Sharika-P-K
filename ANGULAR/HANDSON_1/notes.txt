1. angular.json
Contains Angular project configuration such as build settings, assets, styles and scripts.

2. tsconfig.json
Main TypeScript configuration file.

3. tsconfig.app.json
TypeScript configuration for the Angular application.

4. package.json
Stores project dependencies and npm scripts.

5. src/main.ts
Entry point of the Angular application.

6. src/app/app.config.ts
Configures providers and routing for the standalone Angular application.

7. src/app/app.ts
Defines the root component of the application.

8. src/index.html
Main HTML page where Angular loads the application.

9. maximumWarning
Shows a warning if bundle size exceeds the configured limit.

10. maximumError
Stops the production build if the bundle size exceeds the configured limit.
