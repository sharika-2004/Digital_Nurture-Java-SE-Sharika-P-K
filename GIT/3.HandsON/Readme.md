# Git Hands-on 3 – Branching and Merging

## Objective

- Understand Git branching and merging.
- Create a new branch and commit changes to it.
- Merge the branch into the main branch.
- Delete the branch after a successful merge.

## Prerequisites

- Git installed and configured
- Local Git repository
- Remote GitHub repository

## Branch Created

- GitNewBranch

## Tasks Performed

- Created a new branch named **GitNewBranch**.
- Switched to the new branch.
- Added a new folder and file with sample content.
- Committed the changes to the branch.
- Switched back to the **main** branch.
- Compared the differences between the branches.
- Merged **GitNewBranch** into **main**.
- Verified the commit history using Git log.
- Deleted the merged branch.
- Pushed the merged changes to GitHub.

## Verification

- Verified branch creation and deletion.
- Verified merge using Git log.
- Confirmed repository status was clean after merging.
- Successfully pushed the merged changes to the remote repository.

## Result

Successfully implemented Git Branching and Merging by creating a new branch, committing changes, merging them into the main branch, deleting the feature branch, and synchronizing the repository with GitHub.
